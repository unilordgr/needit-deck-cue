needit Command Center

Looking for computers…

Every computer that runs needit Deck Cue on this network shows up here by itself.

  1. Connect this computer and the show computers to the same network.
  2. Open needit Deck Cue on each show computer.
  3. There, open Settings and switch on Connect to Command Center.

Add a computer

Computers normally appear by themselves. If one doesn't, type the address that its Deck Cue shows under Settings › Command Center.

Saved timers

One click on a saved timer sets it and starts it. Give one a name if it helps, like "Keynote" or "Q&A".

Settings

Only needed if you typed a network key on the show computers. It stops other people on the network from sending files to them.
