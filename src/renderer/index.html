    Command Center

    One computer on the network can send presentations to this one and run them. It needs the needit Command Center app.

    Playing presentations

    How decks open and what happens when you go from one cue to the next.

    Keyboard shortcuts

    These work even while the slideshow is in front. Each needs a modifier key (⌘ ⌃ ⌥, or Ctrl / Alt on Windows) or an F-key, so they never block the clicker. Shortcuts for single cues are set in each cue.

    Presenter remote

    Speakers change their own slides from their phone. They only get Next and Previous, and you can pause it at any time.

    Main and backup

    A second computer follows this one cue for cue, ready to take over if this one fails.

    Stream Deck and remote

    For Bitfocus Companion, Stream Deck, OSC from a lighting desk, and the stage display.

    MIDI

    Fire cues from a MIDI keyboard, a lighting desk or QLab.
